## Why Argos

<CardGrid>
  <Card title="Git-native" icon="document">
    Every request, environment and folder is a YAML file. Diffs review like
    code; merges resolve like code; secrets stay out of the cloud.
  </Card>
  <Card title="One protocol switch" icon="random">
    REST, GraphQL and WebSocket live in the same workspace and the same tab
    bar — no app-switching when the API does.
  </Card>
  <Card title="CI-ready CLI" icon="seti:bash">
    `argos run` reads the same files the desktop UI does. JUnit / JSON / HTML
    reporters drop into GitHub Actions and GitLab CI without glue code.
  </Card>
  <Card title="Imports everything" icon="document">
    Postman v2.1, Insomnia v4, Bruno, OpenAPI 3.x and raw `curl` snippets
    drop in via a single drag-and-drop wizard.
  </Card>
</CardGrid>

## Quick taste

```sh
# Run a collection in CI with JUnit output GitHub Actions picks up.
argos run ./collections \
  --env ci \
  --reporter junit=argos-report.xml \
  --iteration-data ./fixtures/users.csv
```

```yaml
# A single request — version-controlled, diff-friendly.
kind: request
name: List users
type: rest
method: GET
url: "{{baseUrl}}/users"
headers:
  - name: Accept
    value: application/json
auth:
  type: bearer
  token: "{{token}}"
scripts:
  tests: |
    bru.test('status 200', () => {
      bru.expect(bru.res.status).toBe(200);
    });
```
